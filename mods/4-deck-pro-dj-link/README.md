# 4 Deck Pro DJ Link

Makes PRO DJ LINK data available for all four internal decks while retaining the original external-player setup when normal LINK is enabled.

| Normal PRO DJ LINK setting | Function |
|---|---|
| Off | Four internal decks with PRO DJ LINK data transmission. |
| On | Original two internal decks plus two external players on decks 3/4. |

Enable or disable the mod through Community Mods and use its existing Reload control. There is no additional settings switch.

## Requirements

XDJ-AZ with AZ-MODS 1.2.3 or newer.

## Installation

1. Add `twistedmind-afk/Twisted-AZ-Mods` under **Community Mods > Repositories** and install **4 Deck Pro DJ Link** from Browse. Alternatively, merge its USB ZIP's mod folder onto your USB drive.
2. Activate the mod and Reload when requested.
3. Wait for the USB library to load.
4. Leave LINK Off for four internal decks with network data, or turn LINK On for the original 2+2 setup.

Disable older LINK mods and the combined Twisted Load Link first. Reload interrupts playback. Works alongside Change Deck On Load and LED Blink On Air.
