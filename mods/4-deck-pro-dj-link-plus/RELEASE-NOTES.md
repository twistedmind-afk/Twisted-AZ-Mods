# 4 Deck Pro DJ Link Plus 1.0.1

- Added selectable 3 internal + 1 external deck mode, with Deck 3 or Deck 4 reserved for an external player.
- Retained four internal LINK decks with native PRO DJ LINK Off and the original 2+2 mode with LINK On.
- Fixed the thick, centered playhead caused by Compact Track Info on the identified affected Core build.
- Integrated the compatibility correction directly into Plus; no separate Core replacement is required.
- Preserved native Left/Center waveform preferences. Unsupported Core builds or occupied hooks skip the compatibility helper.

Choose the deck layout before Reload. Disable other LINK role mods before enabling Plus.

If needed: set Waveform Current Position to Center, open BROWSE once, then return and set Left.
