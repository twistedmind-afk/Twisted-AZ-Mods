# 4 Deck Pro DJ Link Plus 1.0.1

- Four internal LINK decks with native PRO DJ LINK Off.
- Original 2+2 or selectable 3 internal + 1 external, reserving Deck 3 or Deck 4, with native LINK On.
- Integrated build-specific compatibility hook for the Compact Track Info playhead issue. No separate Core replacement is included or required.
- Native Left/Center preferences remain native. Unknown Core versions or occupied hooks skip the helper.

Disable any other LINK role mod before enabling Plus. Approve the new binary in Community Mods and Reload. Choose 3+1 and the external slot before Reload; deck assignment is not changed live.

Fallback: SHORTCUT > Waveform Current Position > Center, open BROWSE once, then return to SHORTCUT and choose Left. Do not skip BROWSE between Center and Left. Alternatively disable Compact Track Info.

The integrated 1.0.1 helper is awaiting hardware validation. Built and SDK package-validated; no additional emulator playback tests were performed for this release. Previous 3+1 emulator checks apply to the unchanged LINK role implementation, not a guarantee of hardware SYNC or long-session stability.

Source, build instructions and known issues are included in this repository. GPL-3.0-only.
