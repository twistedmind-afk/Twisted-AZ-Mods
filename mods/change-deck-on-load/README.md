# Change Deck On Load

Two independent track-loading shortcuts for the XDJ-AZ.

| Setting | Function | Default |
|---|---|---|
| Select Deck on Load | Select the corresponding deck after a successful track load. | On |
| Load Track on Deck Select | Press SELECT in the track list to load the highlighted track into that deck. | Off |

Use either shortcut or both. Outside the track list, SELECT retains its usual function. Settings take effect immediately. Automatic selection after loading can replace a manual selection made just before the load finishes. Loading into an ON AIR deck is not blocked.

## Requirements

XDJ-AZ with AZ-MODS 1.2.3 or newer.

## Installation

Add `twistedmind-afk/Twisted-AZ-Mods` under **Community Mods > Repositories**, install **Change Deck On Load** from Browse, activate it and Reload when requested. Alternatively, merge its USB ZIP's mod folder onto your USB drive.

Disable older loading/selection mods and the combined Twisted Load Link first. Reload interrupts playback. Works alongside LED Blink On Air and 4 Deck Pro DJ Link.
